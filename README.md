# DigitEgal Empfehlungsecke

Dieses Paket enthält die GUI, die DigitEgal-Logos und die aktuelle
Empfehlungssammlung als Windows-Internetverknüpfungen.

## In drei Schritten starten

1. Das ZIP vollständig in einen beliebigen Ordner entpacken.
2. `INSTALLIEREN.bat` doppelklicken. Das Script installiert Python bei Bedarf
   ohne Administratorrechte und richtet die Anwendung ein.
3. Anschließend `STARTEN.bat` doppelklicken.

Die Sammlung kann später direkt in der App über **Ordner wählen** gewechselt
werden. Über **Aktuelle Sammlung herunterladen** im Kopfbereich gelangt man zu
neuen Empfehlungen auf [digitegal.de](https://digitegal.de/empfehlungsecke/).

## Paketinhalt

- `empfehlungsecke_gui` – Anwendung, Installationsskript und Marken-Assets
- `000_Empfehlungsecke` – die beim Start voreingestellte Link-Sammlung

Die detaillierte technische Dokumentation liegt in
`empfehlungsecke_gui/README.md`.
